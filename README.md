# Экономика информатизации — самостоятельная задача №2

## Расчёт критической массы и ценности социальной сети

Проект содержит воспроизводимую экономическую модель для социальной сети «ГородСоцСеть». Расчёты выполнены по условию экзаменационной задачи и проверены независимо от укрупнённого решения, приведённого в учебных материалах.

## Основной результат модели

В строгом сценарии используются параметры из условия: ARPU — 15 руб./пользователь в месяц, CAC — 500 руб., темп роста до критической массы — 3% в месяц, затраты на поддержание — 2 млн руб. в месяц. При таких параметрах критическая масса недостижима в пределах рынка 1 млн пользователей.

Модель отдельно показывает операционную гипотезу снижения CAC и комбинированный сценарий. Эти сценарии не подменяют исходное условие, а помогают провести экономический анализ: определить, какие параметры нужно изменить для достижения безубыточности.

## Методические решения

1. Новые пользователи считаются по фактической разнице `Nₜ − Nₜ₋₁`, поэтому CAC не умножается на произвольно выбранный прирост рынка.
2. Критическая масса рассчитывается из условия `ARPU × N ≥ Cmaint + CAC × (Nₜ − Nₜ₋₁)` с преобразованием доли новых пользователей `g/(1+g)`.
3. Номинальная ставка 12% годовых преобразуется в эффективную месячную ставку: `(1+0,12)^(1/12)−1`.
4. NPV строится по фактическим помесячным прибылям; потенциальная ценность по Мэткалфу в денежный поток не добавляется.
5. Все сценарии пересчитывают критическую массу, путь пользователей, прибыль и NPV заново.
